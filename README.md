# pihole-blacklist

Eigene Pi-hole Blockliste mit Domains, die im AdBlock-Tester noch nicht geblockt wurden.

## In Pi-hole einbinden

Unter **Lists** diese URL hinzufügen und danach `pihole -g` ausführen:

```
https://raw.githubusercontent.com/Raccoonscityttv/pihole-blacklist/main/rote-domains.txt
```

## Hinweis

Am Ende der Liste stehen Domains, die Apps oder Webseiten beeinträchtigen können
(YouTube-Videos, Instagram, Cookie-Banner). Bei Problemen dort zuerst nachsehen.
